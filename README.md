# Neon Catcher

A high-graphics arcade mini-game built with pure HTML5 canvas.

A glowing ball bounces around a neon arena — steer your catcher tile left/right and drop it downward to snag the ball before it slips past.

## Play

Live: https://cyberking-coder.github.io/newgame/

## Controls

- Arrow keys / A D — move tile left/right
- Down arrow / S — drop tile downward to catch
- Space — pause
- Touch / drag — move the tile with your finger

## Features

- Neon aesthetic with gradient background, animated star field, and a scrolling grid horizon
- Physics-based bouncing ball with gravity, air drag, and trail
- Particle bursts on catch and life-loss, screen shake, and flash effects
- Combo multiplier, best-score persistence, and touch controls for mobile
